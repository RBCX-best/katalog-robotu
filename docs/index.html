Jak přidat robota do katalogu?

Celý katalog funguje plně automatizovaně prostřednictvím GitHub Issues a GitHub Actions.

1

Vytvořte Issue

Otevřete nové Issue v repozitáři a zvolte šablonu Nový robot.

2

Vyplňte formulář

Zadejte název, soutěž, tým a přetáhněte fotku robota přímo do formuláře.

3

Schválení

Administrátor kroužku zkontroluje Issue a přidá label schvaleno.

4

Automatický web

GitHub Action stáhne fotku, uloží data a robot se ihned zobrazí zde na webu!
